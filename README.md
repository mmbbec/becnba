# NBA Automation System

A full‑featured web application for managing NBA (National Board of Accreditation) documentation and tasks for the Electrical & Electronics Engineering program.

## Features

- **User Authentication** – Role‑based login (Super Admin, NBA Coordinator, HoD, Criterion Coordinator, Course Coordinator, Faculty, Documentation Staff, Reviewer).
- **Dashboard** – Overview of tasks, documents, and criteria progress.
- **Task Management** – View assigned tasks with deadlines and status.
- **Document Upload** – Submit evidence files with metadata (criterion, document type, academic year, etc.).
- **Document Management** – Master list of all required documents per criterion. View status, upload, edit details, and access sample templates.
- **Template Support** – Sample templates for each document type. If a template is not available, the system provides a generic outline to prepare a new one.
- **Responsive Design** – Works on desktop, tablet, and mobile.

## Technologies

- HTML5, CSS3, Vanilla JavaScript
- LocalStorage (demo data persistence)
- No external libraries – pure frontend
